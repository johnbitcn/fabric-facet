# Facet - Minecraft ブロック数カウントとアウトライン補助 Mod

[English](./README.md) | [简体中文](./README.zh-CN.md) | [日本語](./README.ja-JP.md)

公式プロジェクトページ：[Modrinth](https://modrinth.com/project/lW1ulmxe) | [CurseForge](https://legacy.curseforge.com/minecraft/mc-mods/facet)

Facet は、Minecraft のブロック数カウント、ブロックアウトライン、距離確認、マンハッタン経路の測定、グラフィティによる目印を補助する軽量な Fabric / NeoForge クライアントサイド Mod です。建築、床張り、区画整理、ルート設計、大規模プロジェクトでブロックを数えたり目印を付けたりしやすくしながら、お気に入りのリソースパックのテクスチャはそのまま使えます。

## 理念と開発意図

Facet の目的はシンプルです。ブロックを数えやすくしつつ、プレイヤーが好きなテクスチャを犠牲にしないことです。多くの Minecraft リソースパックは、ブロックのテクスチャ自体に恒久的な境界線を追加します。これはカウントには便利ですが、すべてのブロックの見た目を常に変えてしまいます。Facet は境界線をクライアント側の描画オーバーレイとして重ねるため、バニラテクスチャ、カスタムリソースパック、シェーダー向けのテクスチャを変更したり上書きしたりしません。

ブロックを数えたいときは、キー割り当てで全ブロックのアウトライン、対象ブロックのアウトライン、距離 HUD を切り替えられます。必要がなくなったらオフにして、普段の見た目のままプレイを続けられます。長い距離を測る場面では、マンハッタン経路インジケーターがプレイヤー足元のブロックから対象ブロックまでの X、Z、Y 方向の経路を示し、HUD には X、Z、Y と合計マンハッタン距離が表示されるため、経路上のブロック数をひと目で確認できます。

グラフィティ機能は、建築中にブロックへ目印を付けるための機能で、探索時の道しるべとしても使えます。対応するブロック面に照準を合わせてグラフィティホイールを開くと、マーカーを選択できます。グラフィティの保存と描画はクライアント側だけで行われるため、ほかのプレイヤーには見えません。印を付けたブロックが移動または破壊されると、そのグラフィティも削除されます。

## 機能アップデート

### v1.2.11 — NeoForge 対応と設定画面へのアクセス

- Minecraft 26.1、26.1.2、26.2 向けの完全な NeoForge ビルドを追加
- ブロックアウトライン、ホバーアウトライン、距離 HUD と経路、クライアント側グラフィティ、ホログラム配置プレビューを NeoForge で利用可能に
- デフォルトで未割り当ての「Facet 設定を開く」キー割り当てを追加し、NeoForge の標準 Mod リストからも設定を開けるように

### v1.2.9 — 主要描画ロジックの再構築

- アウトライン描画ロジックを見直し、より高速で自然な見た目に改善
- 対象ブロックアウトラインの表現ロジックを変更
- ホログラム配置プレビューの描画を修正
- 現在対応する Loader とゲームバージョンは上記一覧を参照

### v1.2.1 — ホログラム配置プレビュー（2026-07-21）

- ブロックをより正確に配置できるよう、リアルタイムのホログラム配置プレビューを追加

### v1.1.2 — クライアント側グラフィティ（2026-07-19）

- 建築や探索の道しるべに使える 4 種類のクライアント側グラフィティマーカーを追加
- `G` で開くアニメーション付きホイールを追加し、数字キーとマウスによる選択に対応
- ワールドとディメンションごとのローカル保存を追加し、ほかのプレイヤーには表示されない仕様を維持
- 印を付けたブロックが移動、破壊、置換されたときの自動削除を追加
- Minecraft 26.2 でグラフィティホイールを開閉するときに画面が一瞬点滅する問題を修正

### v1.0.0 — ブロック数カウントの基礎機能（2026-07-13）

- リソースパックのテクスチャを保ったまま使える、切り替え可能なブロックアウトラインを追加
- 通常のインタラクション範囲外にも対応する、対象ブロック用ネオンアウトラインを追加
- X、Z、Y と合計マンハッタン距離を表示する距離 HUD を追加
- 経路区間を色分けするマンハッタン経路インジケーターを追加
- アウトラインの不透明度、幅、対象ブロックアウトラインのスタイルを調整するクライアント側設定を追加

## キー割り当て

- 全ブロックアウトラインの切り替え
- 対象ブロックアウトラインの切り替え
- ブロック距離カウント HUD とマンハッタン経路表示の切り替え
- Facet 設定を開く（デフォルトでは未割り当て。NeoForge では Mod リストからも開けます）
- グラフィティホイールを開く（デフォルトは `G`、`1`～`4` またはマウスでマーカーを選択）
