针对API做了一些优化，并增加fabric 26.4 snapshot 5 的支持

- 适配新版 Fabric API 和 NeoForge。
- 明确各目标的最低运行依赖，避免加载不兼容的旧版 API。
- 适配新版 NeoForge 的模组列表图标显示。

Minecraft 26.4 Snapshot 5 支持通过独立的 Alpha 预览版提供，不包含在下列正式版文件中。

### 安装要求

所有版本均需要 Java 25。请使用与 Minecraft 版本、加载器对应的 Facet 文件。

| Minecraft | 加载器最低版本 | Fabric API 最低版本 |
| --- | --- | --- |
| 26.1（Fabric） | Fabric Loader 0.18.4 | 0.145.1+26.1 |
| 26.2（Fabric） | Fabric Loader 0.18.4 | 0.153.0+26.2 |
| 26.3（Fabric） | Fabric Loader 0.19.3 | 0.160.5+26.3 |
| 26.1（NeoForge） | NeoForge 26.1.0.19-beta | 不需要 |
| 26.1.2（NeoForge） | NeoForge 26.1.2.47-beta | 不需要 |
| 26.2（NeoForge） | NeoForge 26.2.0.50-beta | 不需要 |
| 26.3（NeoForge） | NeoForge 26.3.0.43-beta | 不需要 |

Mod Menu 为可选依赖。安装它时，还需满足它自身的运行要求。

### 已知上游问题

部分 macOS 环境下，NeoForge 26.3 可能停在启动加载窗口，无模组时也可复现。

如遇此问题，请关闭游戏，在实例的 `config/fml.toml` 中设置：

```toml
earlyWindowControl = false
```

此设置关闭启动加载窗口，不关闭游戏内渲染。
