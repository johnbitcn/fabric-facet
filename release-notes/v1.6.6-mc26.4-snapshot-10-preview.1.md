新增对 Fabric 26.4 Snapshot 10 的支持。

- 更新至 Minecraft 26.4 Snapshot 10。
- 更新 Fabric API 依赖并适配原版新版方块渲染接口。

此版本仅适用于 Minecraft 26.4 Snapshot 10，属于 Alpha 测试版。
不适用于 Snapshot 7 或其他 Minecraft 版本。

最低运行要求：
- Java 25
- Fabric Loader 0.20.0
- Fabric API 0.166.3+26.4

已完成构建、77 项 Java 测试、20 项 Python 测试、开发客户端资源初始化及游戏内测试验收。
macOS 上仍有上游 JOML `Unsafe` 警告。

请移除旧版 Facet 后再安装，不要同时保留多个 Facet JAR。
