新增对 Fabric 26.4 Snapshot 7 的支持。

- 更新至 Minecraft 26.4 Snapshot 7。
- 更新 Fabric API 依赖。

此版本仅适用于 Minecraft 26.4 Snapshot 7，属于 Alpha 测试版。
不适用于 Snapshot 6 或其他 Minecraft 版本。

最低运行要求：
- Java 25
- Fabric Loader 0.20.0
- Fabric API 0.165.4+26.4

已完成构建、76 项 Java 测试、20 项 Python 测试和开发客户端资源初始化。
游戏内显示、功能开关和手动资源重载仍待验证。
macOS 上仍有上游 JOML `Unsafe` 和 MoltenVK primitive-restart 警告。

请移除旧版 Facet 后再安装，不要同时保留多个 Facet JAR。
