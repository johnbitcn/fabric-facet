新增对 Minecraft 26.4 Pre-release 2（Fabric）的支持。

- 修复启用“改进透明度”时，显示全息放置预览边线可能导致游戏崩溃的问题。

这是 Alpha 测试版，仅适用于 Minecraft `26.4-pre-2`。请移除旧版 Facet，不要同时安装多个 Facet JAR。

最低运行要求：
- Java 25
- Fabric Loader 0.20.0（本机使用 0.20.1 验证）
- [Fabric API 0.167.1+26.4](https://modrinth.com/mod/fabric-api/version/e3fLe6Cu)。发布时 Modrinth 仅将该依赖标注为 `26.4-pre-1`，但此版本已在 `26.4-pre-2` 实测可用。若启动器未自动安装，请手动安装此依赖。

已在单人测试世界检查传统和改进透明度、功能开关及资源重载。尚未完成完整的游戏内视觉验收。
